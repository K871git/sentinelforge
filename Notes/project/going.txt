================================================================================
  API RESPONSE FORMAT — STANDARD
================================================================================

  List:        { "status": true, "data": [...], "meta": {pagination} }
  Single:      { "status": true, "data": {...} }
  Created:     { "status": true, "message": "Created.", "data": {...} }   201
  Validation:  { "message": "...", "errors": {...} }                      422
  Unauth:      { "status": false, "message": "Unauthenticated." }         401
  Forbidden:   { "status": false, "message": "Forbidden." }               403
  Error:       { "status": false, "message": "Something went wrong." }    500
